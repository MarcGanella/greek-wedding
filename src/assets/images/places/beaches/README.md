# Fotos propias de las playas

Añade las fotografías locales con estos nombres exactos:

- `temeni.jpg`
- `valimitika.jpg`
- `digeliotika.jpg`
- `aliki.jpg` (Alikes)
- `akoli.jpg` (Akolis)
- `selianitika.jpg`

Cada foto aparecerá en su tarjeta de `/local-places`. Si falta un archivo, la
tarjeta muestra el contenido sin imagen, sin huecos ni peticiones fallidas.

Usa JPEG comprimidos para web: las imágenes se cargan de forma diferida y se
muestran en proporción 3:2 con recorte centrado. El CSS no reduce el peso del archivo.
Los textos alternativos están traducidos en `src/i18n/translations.js`.
